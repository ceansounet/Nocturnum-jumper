# Nocturnum jumper

Hey, this is my game submission for the haven jumpstart program, you can check it out [here](https://ceansounet.itch.io/nocturnum-jumper) !

the game is a simple, single level jumper, you need to collect a key which opens a chest, and the key inside the chest opens the door to the end, but beware, the final jump is only possible if you gather an item.
(q and d for left and right, space to jump, and shift to dash)
